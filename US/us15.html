Ejercicio 1: Modelos de Gestión de Calidad

UI/UX Review

Revisar la interfaz del "Punto de situación" para evaluar su usabilidad y verificar la adherencia a la lista de chequeo de Design QA, comparando los mockups de Figma contra el código maquetado.

Estado: Solución visible

  1. Crear la lista de chequeo (checklist) de Design QA.
  2. Revisar correspondencia entre Figma y código: colores, espaciados y componentes.
  3. Probar usabilidad con usuarios reales, evaluando interacciones, estados y respuesta responsive.

Ejercicio 2: Configuración de Métricas Clave

Métricas

Definir un conjunto de métricas clave de calidad de software para un proyecto de e-commerce con los objetivos de "Mejora Continua" y "Detección Temprana".

Estado: Solución oculta

  1. Medir la densidad de defectos: errores detectados por módulo o Sprint.
  2. Evaluar la cobertura de pruebas: porcentaje de código o requisitos cubiertos.
  3. Calcular la tasa de reapertura de bugs y el tiempo medio de resolución (MTTR).

Ejercicio 3: Automatización en Integración Continua

DevOps / QA · CI/CD

Configurar un pipeline en GitHub Actions que ejecute automáticamente las pruebas unitarias y de integración tras cada Pull Request hacia la rama principal.

Estado: Solución oculta

  1. Crear el archivo de flujo de trabajo .github/workflows/test.yml.
  2. Definir los disparadores para eventos pull_request dirigidos a la rama main.
  3. Configurar la instalación de dependencias, la ejecución del linter y la suite de pruebas, generando un reporte de cobertura.

Ejercicio 4: Estrategia de Pruebas de Carga y Estrés

Rendimiento

Diseñar un escenario de pruebas de rendimiento utilizando JMeter para validar la capacidad de respuesta del sistema durante un evento de alta concurrencia, como CyberMonday.

Estado: Solución oculta

  1. Establecer la línea base de usuarios concurrentes simultáneos, por ejemplo, 5.000 usuarios.
  2. Configurar un Thread Group en JMeter con una rampa de carga progresiva (ramp-up) de 10 minutos.
  3. Definir umbrales de aceptación: tiempo de respuesta inferior a 2 segundos y tasa de error HTTP inferior al 1 %.
